## Key knowledge

**Package manager:** `pip`

**Verification commands**

- `install`: `python3 -m pip install -r requirements.txt`
- `test`: `pytest -q`
- `lint`: `flake8 .`
- `typecheck`: `mypy .`
- `smoke`: `python -m src.main`

**Layout**

- src/ – package containing the application code
- tests/ – test suite (pytest)
- requirements.txt – pinned third‑party dependencies (currently only pytest)
- example.db – SQLite file created at runtime (not committed)

**Skeleton files**

- `requirements.txt` — List third‑party dependencies
- `src/__init__.py` — Make src a package
- `src/main.py` — Minimal app that creates an SQLite DB and inserts a row
- `tests/__init__.py` — Make tests a package
- `tests/test_main.py` — Simple pytest that verifies the DB is created and contains the expected row

**Gotchas**

- Make sure you run commands from the repository root so that the src package is on the import path.
- SQLite is bundled with Python, so no external driver is needed.
- If you use a virtual environment, activate it before installing requirements.
- The test rewrites the module‑level DB_PATH; this is safe because the variable is mutable.
- Running the smoke command creates a file named example.db in the repository root; you may want to add it to .gitignore.

**Sources consulted**

- https://docs.python.org/3/library/sqlite3.html
- https://docs.python.org/3/tutorial/modules.html
- https://pytest.org/
