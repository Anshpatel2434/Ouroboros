## Key knowledge

**Package manager:** `pip`

**Verification commands**

- `install`: `pip install -r requirements.txt`
- `test`: `python -m unittest discover`
- `lint`: `flake8`
- `typecheck`: `mypy`
- `smoke`: `python -c 'print("Hello, World!")'`

**Layout**

- Project root contains main application files and directories.
- Tests are located in a separate 'tests' directory.

**Skeleton files**

- `main.py` — Main application file that runs the application.

**Gotchas**

- Ensure Python 3.10 is installed and available in your PATH.
- If using virtual environments, activate it before running commands.
- Make sure to create a requirements.txt file even if it's empty to avoid errors during install.
