## Key knowledge

**Package manager:** `uv`

**Verification commands**

- `install`: `uv sync --no-dev`
- `test`: `uv run pytest -q`
- `lint`: `uv run ruff check .`
- `typecheck`: `uv run mypy .`
- `smoke`: `uv run python -c "import click, sqlite3; print('smoke ok')"`

**Layout**

- Source code lives under a top‑level `src/` package; this is the default layout expected by uv and many linters.
- Tests are placed in a top‑level `tests/` directory and use pytest.
- The `pyproject.toml` defines the project metadata, dependencies, and the Click console script entry point.

**Skeleton files**

- `pyproject.toml` — Project metadata, dependencies, and console script entry point.
- `src/fts_cli/__init__.py` — Make src/fts_cli a package.
- `src/fts_cli/main.py` — Minimal Click CLI that creates an SQLite DB with an FTS5 virtual table and provides a search command.
- `tests/test_cli.py` — Smoke test that the CLI commands run and produce expected output.

**Gotchas**

- uv requires a pyproject.toml; ensure the file is present before running any uv command.
- SQLite FTS5 is compiled into the Python stdlib sqlite3 module on most platforms, but on some Linux distributions you may need the libsqlite3-dev package at build time.
- Click commands are discovered via entry points; the pyproject.toml must declare the console script.
- Running `uv sync` will create a .venv directory by default; keep it out of version control.
