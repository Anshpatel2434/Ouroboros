## Key knowledge

**Package manager:** `npm`

**Verification commands**

- `install`: `npm install`
- `test`: `npm test`
- `lint`: `npm run lint`
- `typecheck`: `npm run typecheck`
- `build`: `npm run build`
- `smoke`: `npm start`

**Layout**

- The project follows the Angular CLI structure, which includes src, e2e, and other standard directories.

**Skeleton files**

- `src/app/app.component.ts` — Main application component

**Gotchas**

- Ensure you have Node.js installed (version 14.x or later is recommended).
- Angular CLI must be installed globally: `npm install -g @angular/cli`.
- The initial project setup can be done using `ng new my-angular-app` which creates a new Angular project with a default structure.
